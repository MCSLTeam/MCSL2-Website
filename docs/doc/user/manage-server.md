# 管理服务器

在服务器管理页面，您可以对已创建的服务器进行管理、启动、编辑和删除等操作。

## 服务器列表

管理页面会显示所有已创建的服务器，每个服务器卡片包含以下信息：

- 服务器图标
- 服务器名称
- 核心文件名
- 快捷操作按钮

![服务器列表](https://img.fastmirror.net/s/2023/12/08/657337a4c8f9e.png)

## 启动服务器

点击服务器卡片上的 `启动` 按钮即可启动服务器。

:::tip 提示
首次启动服务器时，可能需要同意 Minecraft EULA 协议。MCSL2 会自动提示您。
:::

### 服务器自启动

MCSL2 v2.3+ 支持以下自启动功能：

- **MCSL2 开机自启**：在设置中启用后，MCSL2 将随系统启动
- **服务器随 MCSL2 自启**：在服务器设置中启用后，该服务器将在 MCSL2 启动时自动运行

## 编辑服务器

点击服务器卡片上的 `编辑` 按钮，可以修改服务器的以下配置：

- 服务器名称
- 核心文件
- Java 路径
- 内存设置（最小/最大内存）
- JVM 参数
- 输入输出编码
- 服务器图标
- 自启动设置

:::warning 注意
修改服务器配置后需要重启服务器才能生效。
:::

## 删除服务器

点击服务器卡片上的 `删除` 按钮可以删除服务器。

:::danger 警告
删除服务器会同时删除服务器文件夹及其所有内容，此操作**不可恢复**！请谨慎操作。
:::

## 服务器文件管理

### 打开服务器文件夹

点击 `打开文件夹` 按钮可以在文件管理器中打开服务器所在目录。

### 编辑服务器文件

MCSL2 v2.3+ 内置了支持**语法高亮**的文本编辑器，可以直接编辑以下文件：

- `server.properties` - 服务器配置文件
- `eula.txt` - EULA 协议
- `.yml`/`.yaml` - 插件配置文件
- `.json` - JSON 配置文件
- `.txt` - 文本文件

:::tip 提示
编辑 `server.properties` 时，编辑器会提供语法高亮，方便您修改配置。
:::

## Forge/NeoForge 服务器管理

对于 Forge 和 NeoForge 服务器，MCSL2 提供了以下特殊支持：

### 自动安装

当您拖入 Forge/NeoForge installer 时：

1. MCSL2 会自动识别安装器类型和版本
2. 提示是否需要自动安装服务端
3. 显示安装进度（下载依赖库、处理器运行等）
4. 自动配置 JVM 参数

:::tip BMCLAPI 镜像支持
MCSL2 支持使用 BMCLAPI 镜像加速 Forge/NeoForge 依赖库下载。可在设置中分别配置 Forge 和 NeoForge 是否使用镜像。
:::

### 版本信息显示

安装完成后，服务器的 `extraData` 会保存版本信息：

- **Forge**: `mc_version` 和 `forge_version`
- **NeoForge**: `mc_version` 和 `neoforge_version`

## 基岩版服务器

MCSL2 v2.3+ 支持基岩版（Bedrock Edition）服务器：

- 自动识别基岩版服务器核心
- 支持 BDS (Bedrock Dedicated Server)
- 可在下载页面直接下载基岩版服务端

## 计划任务

MCSL2 v2.3+ 新增计划任务功能，可以设置服务器的定时操作：

- 定时启动服务器
- 定时关闭服务器
- 定时执行命令
- 定时备份

前往 `计划任务` 页面配置详细的任务计划。

## 故障排查

### AI 报错分析

MCSL2 v2.3+ 集成了 AI 报错分析功能：

1. 当服务器启动失败或出现错误时
2. 点击 `AI 分析` 按钮
3. 系统会自动分析错误日志并给出解决建议

:::tip 提示
本地报错分析不需要联网，完全离线工作。
:::

### 常见问题

#### 服务器无法启动

- 检查 Java 版本是否匹配
- 查看是否有其他程序占用端口
- 确认 EULA 协议已同意
- 检查内存设置是否合理

#### Forge/NeoForge 安装失败

- 尝试启用 BMCLAPI 镜像
- 检查网络连接
- 确保有足够的磁盘空间
- 查看安装日志获取详细错误信息

## 多服务器管理技巧

### 服务器分组

为不同类型的服务器设置不同的图标，便于区分：

- 原版服务器：草方块图标
- Mod 服务器：铁砧图标
- 插件服务器：红石图标

### 批量操作

虽然 MCSL2 目前不支持批量操作，但您可以：

- 使用统一的命名规范
- 为相似服务器使用相同的 JVM 参数
- 利用导入功能快速复制服务器配置
