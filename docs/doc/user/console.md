# 终端

终端（控制台）是与 Minecraft 服务器交互的核心界面，您可以在这里查看服务器日志、执行命令、管理玩家等。

## 进入终端

启动服务器后，点击服务器卡片上的 `终端` 按钮即可打开控制台窗口。

![控制台界面](https://img.fastmirror.net/s/2023/12/08/65733c4d8f9a1.png)

## 控制台界面

### 日志输出区域

控制台顶部是服务器日志输出区域，会实时显示：

- 服务器启动日志
- 玩家加入/退出信息
- 游戏事件日志
- 错误和警告信息
- 插件/模组输出

:::tip 提示
日志会自动保存到 `MCSL2/Logs/` 目录，方便后续查看。
:::

### 命令输入框

控制台底部是命令输入框，您可以在这里输入 Minecraft 命令或控制服务器。

## 执行命令

### Minecraft 内置命令

MCSL2 支持所有 Minecraft 原版命令，并提供**智能补全**功能：

```
/op <玩家名>           # 给予玩家管理员权限
/gamemode <模式> <玩家> # 更改游戏模式
/give <玩家> <物品>     # 给予玩家物品
/tp <玩家1> <玩家2>     # 传送玩家
/time set <时间>       # 设置时间
/weather <天气>        # 设置天气
/difficulty <难度>     # 设置难度
/stop                 # 关闭服务器
```

:::tip 智能补全
输入 `/` 后，MCSL2 会自动提示可用的命令。使用 `Tab` 键或方向键可以快速选择。
:::

### 命令历史记录

MCSL2 会记录您执行过的命令：

- 使用 `↑` `↓` 方向键可以快速调用历史命令
- 历史记录在本次会话中保持有效
- 避免重复输入相同命令

### 常用命令快捷方式

MCSL2 提供了一些常用命令的快捷按钮（如果界面支持）：

- `停止服务器` - 相当于 `/stop`
- `保存世界` - 相当于 `/save-all`
- `重载配置` - 相当于 `/reload`

## 编码设置

### 输出编码

服务器日志的字符编码设置，影响日志的显示：

- **跟随全局**：使用 MCSL2 设置中的全局编码
- **UTF-8**：适用于大多数服务器
- **GB18030**：适用于中文 Windows 服务器
- **ANSI**（仅 Windows）：适用于旧版 Windows 系统

### 输入编码

命令输入的字符编码设置：

- **跟随全局**：使用全局设置
- **跟随输出**：与输出编码保持一致
- **UTF-8**：推荐设置
- **GB18030**：特殊情况下使用

:::warning 乱码问题
如果控制台出现乱码，请尝试调整编码设置。通常情况下：
- Linux/Mac: UTF-8
- Windows: GB18030 或 UTF-8
:::

## 日志管理

### 查看历史日志

所有服务器日志都保存在 `MCSL2/Logs/` 目录下：

```
MCSL2/Logs/
  ├── 服务器名称_YYYY-MM-DD_HH-MM-SS.log
  └── ...
```

### 日志文件命名规则

日志文件按以下格式命名：
```
[服务器名称]_[日期]_[时间].log
```

例如：`MyServer_2026-01-12_14-30-00.log`

### 清理日志

为避免日志文件占用过多空间，建议定期清理：

1. 前往 `MCSL2/Logs/` 目录
2. 删除不需要的旧日志文件
3. 或使用压缩工具归档历史日志

## 性能监控

### 服务器状态显示

控制台可能会显示以下服务器状态信息：

- **TPS**（Ticks Per Second）：服务器运行速度
- **在线玩家数**：当前在线玩家/最大玩家数
- **内存使用**：当前内存使用情况

:::tip TPS 说明
- TPS = 20：服务器运行正常
- TPS < 20：服务器存在卡顿
- TPS < 15：严重卡顿，需要优化
:::

### 查看服务器资源占用

使用以下命令查看详细信息：

```
/tps              # 查看 TPS（需要插件支持）
/mem              # 查看内存使用（需要插件支持）
/gc               # 触发垃圾回收
```

## 玩家管理

### 常用玩家管理命令

```
# 权限管理
/op <玩家名>          # 给予管理员权限
/deop <玩家名>        # 移除管理员权限

# 封禁管理
/ban <玩家名>         # 封禁玩家
/ban-ip <IP>        # 封禁 IP
/pardon <玩家名>      # 解除封禁
/pardon-ip <IP>     # 解除 IP 封禁

# 踢出玩家
/kick <玩家名> [理由]  # 踢出玩家

# 白名单
/whitelist on             # 开启白名单
/whitelist off            # 关闭白名单
/whitelist add <玩家名>    # 添加白名单
/whitelist remove <玩家名> # 移除白名单
/whitelist list           # 查看白名单
```

### 查看在线玩家

```
/list             # 查看在线玩家列表
```

## 服务器控制

### 停止服务器

```
/stop             # 安全停止服务器
```

:::warning 注意
请**不要直接关闭控制台窗口**，这可能导致服务器数据丢失。务必使用 `/stop` 命令正常关闭服务器。
:::

### 保存世界

```
/save-all         # 保存所有世界数据
/save-off         # 禁用自动保存
/save-on          # 启用自动保存
```

### 重载配置

```
/reload           # 重载服务器配置（不推荐）
```

:::danger 关于 /reload
`/reload` 命令可能导致插件/模组出现问题，建议重启服务器而不是使用此命令。
:::

## 多窗口支持

MCSL2 支持同时打开多个服务器的控制台窗口：

- 每个服务器都有独立的控制台
- 可以同时管理多个运行中的服务器
- 窗口之间互不干扰

## 故障排除

### 控制台无响应

如果控制台无法输入命令：

1. 检查服务器是否正常运行
2. 确认服务器没有崩溃
3. 查看日志是否有错误信息
4. 尝试重启服务器

### 日志不显示中文

1. 检查输出编码设置
2. 尝试切换到 UTF-8 或 GB18030
3. 重启服务器使设置生效

### 命令执行无效

1. 确认命令语法正确
2. 检查是否有足够的权限
3. 查看服务器日志中的错误提示
4. 确认插件/模组是否正常加载

## 高级功能

### AI 报错分析

MCSL2 v2.3+ 新增 AI 报错分析功能：

- 当控制台出现错误日志时
- 点击 `AI 分析` 按钮（如果可用）
- 自动分析错误原因并给出解决方案
- 完全本地化，无需联网

### 计划任务联动

在计划任务中可以设置定时执行控制台命令：

- 定时保存世界
- 定时发送公告
- 定时清理掉落物
- 定时备份数据

前往 `计划任务` 页面配置详细任务。
