# 开始使用

快速完成下载、解压、首次运行，并了解主界面导航。

## 下载并启动

1. 前往 [下载页](/download) 获取最新版本
2. 解压压缩包
3. 启动程序：
	- Windows: 双击 `MCSL2.exe`
	- Linux/Mac: 先赋予执行权限再运行

::: details Linux/Mac 无法启动？
```bash
chmod +x MCSL2.bin
./MCSL2.bin
```
若仍失败，可下载源码自行运行。
:::

## 首次进入需要准备

- 至少安装 1 个可用的 Java 版本（推荐在「下载」页获取）
- 确保磁盘有足够空间存放核心与世界（建议 ≥ 5G）
- 网络可访问所选下载源
