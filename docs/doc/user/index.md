# 用户使用文档

欢迎使用 MCSL2！本文档将帮助您快速上手并充分利用 MCSL2 的所有功能。

## 📚 文档导航

### 🚀 [开始使用](/doc/user/get-started)

适合新手的快速入门指南：

- 下载和安装 MCSL2
- 了解主界面布局
- 首次运行设置

### ⚙️ [配置服务器](/doc/user/configure-server)

学习如何创建和配置 Minecraft 服务器：

- **简易模式** - 最简单的服务器创建方式
- **进阶模式** - 自定义 JVM 参数和编码设置
- **导入服务器** - 从其他启动器或压缩包导入
- **Java 版本选择** - 为不同 Minecraft 版本选择合适的 Java
- **Forge/NeoForge 支持** - 自动安装模组服务器

### 📦 [下载资源](/doc/user/downloads)

了解如何使用 MCSL2 的下载功能：

- **4 大镜像站** - FastMirror、MCSLAPI、Polars、雨云
- **核心下载** - 各种服务端核心（Paper、Spigot、Fabric 等）
- **Java 下载** - 自动下载适配的 Java 版本
- **下载任务管理** - 查看和管理下载进度

### 🎮 [管理服务器](/doc/user/manage-server)

掌握服务器的日常管理：

- 启动和停止服务器
- 编辑服务器配置
- 服务器文件管理
- Forge/NeoForge 服务器特殊管理
- 基岩版服务器支持
- 计划任务设置
- AI 报错分析

### 💻 [终端（控制台）](/doc/user/console)

使用控制台与服务器交互：

- 查看服务器日志
- 执行 Minecraft 命令
- 玩家管理命令
- 服务器控制命令
- 智能命令补全
- 编码设置

### 🔌 [MCSL2 插件](/doc/user/plugins)

扩展 MCSL2 的功能：

- 安装和管理插件
- 插件配置
- 寻找插件
- 插件故障排除

## ✨ MCSL2 特色功能

### 🔍 智能 Java 搜索

MCSL2 拥有业界领先的 Java 搜索算法：

- ⚡ **1-2 秒内**找到系统中 95% 的 Java
- 🎯 准确识别 Java 版本
- 🔄 支持多种 Java 发行版

### 🤖 AI 报错分析

MCSL2 v2.3+ 集成了本地 AI 分析：

- 🧠 自动分析服务器错误
- 💡 提供解决方案建议
- 🔒 完全本地化，保护隐私

### 📅 计划任务

定时自动化管理服务器：

- ⏰ 定时启动/关闭服务器
- 💾 自动备份数据
- 📢 定时发送公告
- 🗑️ 定时清理资源

### 🚀 自启动支持

方便的自启动功能：

- 🖥️ MCSL2 开机自启
- 🎮 服务器随 MCSL2 自启
- ⚙️ 灵活的启动配置

### 🎨 Fluent Design

美观现代的界面设计：

- 🌗 深色/浅色主题自动切换
- 🎯 直观的操作流程
- 📱 响应式布局设计
